# STARFALL

A co-op sci-fi looter-shooter for Roblox: 5 classes, a class hall for each one, fireteams of 3, 5 story missions, levels, power and loot, and a story that unlocks week by week. The hub is the starship **Meridian**, in orbit above a broken Earth.

- **`GAME_DESIGN.md`**: the full game design (story, classes, missions, progression, live story, monetization, roadmap)
- **`CLAUDE.md`**: instructions for Claude Code (architecture, testing, first task, improvement backlog)
- **`src/`**: the Luau source code (Rojo project)

## Quick start
1. Install Roblox Studio and the Rojo plugin.
2. Run `rojo serve` in this folder and click **Connect** in the Studio Rojo plugin.
3. Press **Play**. You spawn on the Skydeck. Pick a class, then go to the Mission Table on the Command Deck.
